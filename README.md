# Illimi Solutions Limited — Official Website

![Illimi Solutions](assets/images/banner.png)

**Illimi Solutions Limited** is a professional research and data collection firm headquartered in **Abuja, Federal Capital Territory, Nigeria**. This repository contains the source code for the official Illimi Solutions website.

## 🦟 Current Project: GiveWell Nigeria ITN Programme

Illimi Solutions is currently engaged as the independent monitoring and survey firm for the **GiveWell-funded Insecticide-Treated Net (ITN) distribution programme** in Nigeria (ITN Listing Project — October 2026).

The ITN project page includes:
- Full project introduction and background
- Project objectives and implementation phases
- **Mappers & Listers Training** module (links to Google Drive materials)
- **Baseline Survey Training** module (links to Google Drive materials)

## 🚀 Deployment

This is a static HTML/CSS/JS website. It can be deployed to:
- **GitHub Pages** (free, recommended)
- Netlify
- Any Nigerian web hosting provider

### Enable GitHub Pages
1. Go to repository **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / `root`
4. Save — the site will be live at `https://hypironglobal-eng.github.io/illimi-solutions/`
